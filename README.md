# Doc Checker

## Overview

Check documentation format

## Installation

The package can be installed from the repository with
[uv](https://docs.astral.sh/uv/):

```bash
uv add git+https://github.com/cledouarec/doc-checker
```

## Usage

Run the command line interface:

```bash
doc-checker --version
```
